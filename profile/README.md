### What the API covers

| | |
|---|---|
| **Hotels and OTAs** | Google Hotels (prices, 330-night calendars, room matrix, reviews), Booking.com, Expedia, Hotels.com, Agoda, Tripadvisor, Hostelworld, and hotels' own booking engines for direct rates. Cross-source rate comparison for parity monitoring. |
| **Rentals** | Airbnb and Vrbo search, quotes and availability calendars. |
| **Flights** | Google Flights itineraries, return legs, booking options and fare calendars. |
| **Search, maps and trends** | Google Search, News, Images, Videos, Autocomplete, Shopping, Maps and Trends; Bing. |
| **Jobs** | Google Jobs, LinkedIn Jobs, Indeed and company careers boards. |
| **Retail, apps and reviews** | Amazon, Walmart, Google Play, Apple App Store, YouTube, Trustpilot and G2. |
| **Real estate** | Rightmove and Domain.com.au listings. |

Every response reports the credits it used, errors are typed per HTTP status, and the full [OpenAPI spec](https://scrapercompany.com/openapi.json) is public.

### Quickstart

```bash
curl https://api.scrapercompany.com/v1/markets \
  -H "x-api-key: $SCRAPERCOMPANY_API_KEY"
```

Create an account at [scrapercompany.com](https://scrapercompany.com) to get an API key, then browse the [docs](https://scrapercompany.com/docs) for every endpoint.
