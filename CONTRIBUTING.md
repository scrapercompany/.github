# Contributing

Thanks for helping improve ScraperCompany.

- **Bugs and feature requests** for a repository: open an issue there, using the templates.
- **API problems** (a request failing, wrong data, billing): email support@scrapercompany.com with the `request_id` from the response. Check https://status.scrapercompany.com first.
- **Security issues**: see [SECURITY.md](SECURITY.md); never report them in public.
- **Pull requests**: keep them small and focused, include tests, and describe the change and why. Never commit API keys or other credentials.
