# Security policy

Please report suspected vulnerabilities in ScraperCompany services, websites or client libraries privately to **security@scrapercompany.com**. Do not open a public issue.

Include what you found, the steps to reproduce it and the impact you expect. We acknowledge reports within 3 business days and keep you updated until the issue is resolved. Please give us reasonable time to fix an issue before disclosing it.

Never include real API keys or customer data in a report. If you believe an API key has been exposed, rotate it from your dashboard at https://scrapercompany.com and tell us.

More: https://scrapercompany.com/security
